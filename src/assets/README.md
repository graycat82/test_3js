# 스티커 파생 자산

- 참고 사진: `Pictures/IMG_0098.jpg` (원본은 수정하지 않음).
- `sticker-atlas.webp`: imagegen 편집으로 사진의 패널·서랍·스캐너 표식을 평면 atlas로 재구성. 사진의 정확한 픽셀 크롭이나 실측 복원은 아니며 작은 문자·그림에는 차이가 있다.
- 생성 원본: 1254×1254 PNG. 배포 자산은 같은 크기의 WebP(quality 86, 360,504 bytes)로 인코딩했다.
- 영역: 위 53.7% 패널, y 54.2~75% 서랍, 왼쪽 아래 x 0~50% / y 75.3~100% 스캐너 표식. `textures.ts`에서 패널 외곽을 마스킹하고 CanvasTexture로 변환한다.
- LCD는 이미지의 검은 창 위에 별도 7세그먼트 화면으로 표시한다. 키 문자는 사진을 확대해 사용하는 대신 Canvas로 직접 그린다.
- 원본 사진과 배경·촬영 장소는 빌드에 포함하지 않는다. 홈 화면 아이콘은 별도로 작성한 `public/icons/calculator.svg`를 PNG 180·192·512px로 렌더링한 것이다.
