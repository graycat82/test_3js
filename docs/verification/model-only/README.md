# 모델 전용 화면과 배포 진단

검증일: 2026-10-18.

사용자 요청에 따라 제목, 소개, 진행 단계, 하단 설명을 제거하고 화면 전체를 모델 표시 영역으로 사용한다. 정상 화면의 상태 텍스트는 화면 읽기 프로그램에만 제공한다. 오류가 발생할 때는 오류 안내를 표시한다. 계산·회전·확대·축소 기능은 추가하지 않았다.

**로컬 검증**

- 타입 검사와 프로덕션 빌드 통과.
- 기존 모델 단위 테스트 3개 통과.
- 프로덕션 미리보기 `/test_3js/`에서 1280×900, 390×844 화면 확인.
- 각 크기에서 모델 표시 영역이 안전 여백을 제외한 화면 전체를 사용함을 확인.
- 확인한 로컬 브라우저의 실행 오류 없음. 아이폰 실기기 확인은 별도다.
- [데스크톱 화면](desktop.png), [모바일 화면](mobile.png).

**공개 페이지에서 모델이 보이지 않던 원인**

공개 HTML에서 스크립트가 `/src/main.ts`를 가리키고, 홈 링크의 `%BASE_URL%`가 그대로 남아 있으며 빌드된 CSS 링크가 없었다. Vite의 빌드 결과 대신 원본 HTML이 공개된 상태다.

최초 Deploy to GitHub Pages 실행은 빌드 후 configure-pages에서 Pages 설정을 찾지 못해 실패했다. 이후 별도의 pages-build-deployment 실행이 원본 파일을 공개했다.

Pages 설정의 Source를 GitHub Actions로 지정하고, 이 저장소의 Deploy to GitHub Pages 워크플로가 만든 `dist/`를 배포해야 한다. 원격 설정과 수정본의 공개 배포 결과는 실제 확인 후 기록한다.
