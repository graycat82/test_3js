# 계산 중심 첫 화면

검증일: 2026-10-18. `http://localhost:4173/test_3js/` 프로덕션 빌드를 사용했다.

첫 접속에서 LCD와 숫자·연산 키를 중심으로 크게 보여 준다. ON·OFF·AC도 포함해 계산 키와 LCD가 잘리지 않는 범위에서 화면 비율에 맞는 최대 크기로 잡는다. 제목·설명 UI는 추가하지 않았다. 계산대 전체와 꽃 마이크·스캐너 형상 보정은 유지한다.

- 핀치·휠·축소 버튼으로 다른 부분을 볼 수 있다. 초기 구도의 표적을 유지한 채 축소하며 마이크·스캐너·케이블까지 확인할 수 있게 거리 상한을 설정했다.
- 처음 보기(↺)는 초기 계산 구도로 복귀한다. 기존 계산 보기 버튼은 전체 보기(◇)로 바꿨으며 전체 모델을 사선으로 보여 준다.
- 화면 회전·높이 변경 시 현재 방향과 상대 확대 비율, 계산값을 유지한다.
- 외형 비교용 `?view=default/front/back/left/right`는 해당 방향의 전체 모델로 시작한다. 일반 접속은 쿼리 없이 계산 구도로 시작한다.
