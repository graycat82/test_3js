# 3단계와 4단계 검증 기록

검증일: 2026-10-18. 범위는 시점 조작·입력 판정과 계산·LCD·버튼 애니메이션이다. 추가 요청한 7세그먼트 표시와 입력 후 LCD 백라이트를 포함한다.

**구현 결과**

- OrbitControls의 한 손가락/마우스 회전, 두 손가락 핀치/휠 확대·축소, 거리·상하 회전 제한과 이동 차단.
- 화면 오른쪽 아래 아이콘으로 확대·축소·처음 보기·계산 보기 제공. 제목이나 소개 문구는 추가하지 않음.
- 이동 8 CSS px 초과, 다중 터치, 취소, 화면 크기 변경·앱 전환, 다른 키에서 손 떼기를 계산 입력으로 확정하지 않음.
- 가장 가까운 모델 표면을 검사해 다른 부품에 가려진 키 선택 차단. 캔버스를 벗어날 수 있는 두 번째 손가락의 이동·해제도 document에서 처리.
- decimal.js 기반 입력 순서 계산, 최대 12자리 입력·결과 유효숫자, 소수 정밀도, 음수·지수·오류 표시와 ON/OFF/AC.
- 숫자 폰트를 사용하지 않고 다각형으로 그리는 7세그먼트 LCD. 소수점·부호·지수·Error 표현.
- 유효한 키 입력 후 3초 점등하고 0.25초 동안 소등. 재입력은 점등 시간 연장, OFF는 즉시 소등. 자동 소등 후에도 계산값 유지.
- 눌린 키의 로컬 높이를 내려 실제 눌림 표현. 빠른 탭도 눌림 효과를 보이고, 드래그·취소·앱 전환 시 복귀.
- 정지 상태에서는 렌더링을 예약하지 않고, 백라이트 소등 시작은 타이머로 깨운 뒤 전환 구간만 렌더링.

**자동 검사**

| 검사 | 결과 |
|---|---|
| npm run typecheck | 통과 |
| npm test | 40개 통과 |
| npm run build | 성공; Vite의 엔진 청크 크기 경고는 남음 |
| 테스트 임시 파일 | 디스크 임시 파일 없음; 모델 fixture는 finally에서 자원 해제 |
| 핀치 단위 검증 | DOM EventTarget 대역에서 실제 OrbitControls에 두 포인터를 전달해 확대·축소·거리 제한·이동 차단·재연결 확인 |
| 입력 취소 검증 | 드래그 후 원위치 복귀, 두 손가락 해제 순서, 캔버스 밖에서 시작한 다른 손가락, pointercancel, 늦은 이전 포인터 이벤트, 휠·UI 취소 확인 |
| 계산 검증 | 사칙연산·입력 순서·연산자 교체·반복 =·새 입력·소수·12자리 제한·오류·전원 확인 |
| 백라이트 검증 | 가상 시간으로 3초 유지·0.25초 전환·연장·OFF 확인 |

**브라우저 조작 확인**

환경은 Windows의 Codex 내장 브라우저이며 `http://localhost:4173/test_3js/`의 프로덕션 빌드를 사용했다.

| 사례 | 확인 결과 |
|---|---|
| 실제 3D 키 12 + 34 = | LCD 46, 백라이트 켜짐 |
| 같은 숫자 키 빠르게 두 번 클릭 | LCD 11, 두 입력 모두 처리 |
| 숫자 키에서 드래그 시작 | 카메라 회전, 기존 46 유지, 백라이트 점등하지 않음 |
| 마우스 휠과 확대·축소 아이콘 | 시점 거리 변경, 계산값 유지 |
| 처음 보기·계산 보기 | 목표 시점으로 복귀, 계산값 유지 |
| OFF 후 숫자 키 클릭 | LCD 비어 있음, 백라이트 꺼짐, 입력 차단 |
| ON | LCD 0으로 초기화, 백라이트 점등 |
| 0으로 나누기 | 7세그먼트 Error 표시; 계산 입력 차단 후 AC/ON으로 복구 |
| 점등 후 3.5초 경과 | 백라이트 꺼짐, LCD 46 유지 |
| 모바일 크기 390×844 | 계산 보기에서 실제 3D 키 7 + 8 = 15 확인 |
| 가로 크기 844×390 전환 | 15 유지, 키패드와 LCD 표시 |
| MIC·OPEN 클릭 | 값 15 유지, 백라이트 꺼짐 유지 |
| 브라우저 실행 오류 | 관측 없음 |

**검증의 한계와 후속 범위**

모바일 크기에서의 브라우저 클릭은 실제 아이폰 터치 확인이 아니다. 핀치는 단위 수준의 두 포인터 이벤트 검증이며, 실기기 Safari의 제스처·주소창·GPU 성능·컨텍스트 복구는 후속 검증이 필요하다. 계산 보기는 LCD와 키패드에 집중하므로 주변 장식 부품이 일부 잘릴 수 있다.

스티커의 사진 텍스처 보정, manifest·아이콘, 추가 모바일 최적화, 전체 통합 검증과 아이폰 실기기 확인은 5~7단계에 남겼다. 이 기록은 로컬 검증 결과이며 공개 배포는 GitHub Actions 실행과 공개 페이지에서 별도로 확인한다. 원본 사진은 변경하지 않았다.
