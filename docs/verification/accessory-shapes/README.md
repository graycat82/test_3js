# 마이크·스캐너·OPEN 형상 보정

검증일: 2026-10-18. `IMG_0098.jpg`, `IMG_0099.jpg`, `IMG_0101.jpg`를 비교해 3D 형상을 보정했다. 실측이 없는 깊이·곡률·작은 홈은 사진을 보고 추정했다. 원본 사진과 스티커 이미지는 변경하지 않았다.

- 꽃 마이크: 얇은 빨간 꽃판 앞에 노란 원통형 몸통을 길게 돌출시켰다. 뒤쪽 연결부와 줄기 접점, 앞쪽 둥근 캡·그릴·이음선을 맞췄다. 꽃판 자체를 세로로 늘리는 대신 측면 사진의 몸통 깊이를 반영했다.
- 스캐너: 넓은 둥근 헤드와 아래쪽 이음부, 휘어진 타원 단면 손잡이와 손가락 홈을 만들었다. 작은 측면 오목 표식, 아래쪽 돌출부, 손잡이 끝 케이블 연결부와 줄 경로도 보정했다. 작은 오목 표식은 실제 관통 구멍이 아닌 표면 표현이다.
- OPEN: 뒤쪽은 평평하고 앞쪽은 완만하게 볼록한 윤곽으로 만들었다. 아랫면 가운데가 조금 더 둥글게 내려오도록 보정했다. 키패드 앞의 별도 공간과 문자 가독성을 유지한다.

검증 환경은 Windows Codex 내장 브라우저의 프로덕션 빌드 `http://localhost:4173/test_3js/`다.
